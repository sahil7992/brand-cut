# Demo brand: Tidewell (fictional)
Exists only to prove that swapping brand.json re-themes every archetype (palette, fonts, logo, cast, story, app tokens).
It ships no UI captures: a real brand supplies its own in `assets/ui/` (see research/RESEARCH.md). Archetypes that use captures fall back to the generic UI kit (`shared/uikit`, HF.realui), themed through the `--app-*` tokens. Faces are licence-safe Commons portraits.
